# e-plantShopping
Paradise Nursery is a shopping cart web app for houseplants, built with React and Redux Toolkit.

## Features
- Landing page with a "Get Started" button
- Product listing grouped by plant category, with an "Add to Cart" button
- Navigation bar with a live cart item counter
- Shopping cart page: increase/decrease quantity, delete items, per-item subtotal and total
- Checkout and Continue Shopping buttons

## Tech stack
React, Vite, Redux Toolkit, React-Redux
